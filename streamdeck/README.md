# Marbles Stats Controls for Stream Deck

One installable plugin provides two physical key actions:

- **RaceStats Start / Stop**
- **RaceCycles Start / Stop**

Requires Windows 10+ and Elgato Stream Deck desktop software 7.0+. The plugin uses Stream Deck's included Node.js 20 runtime; its WebSocket library is bundled, so end users do not need Node or npm installed.

Key artwork is generated by the application's actual `sidebarArtwork` renderer: RaceStats uses the sidebar's ranking/star icon, RaceCycles its cycle icon, and MoS Drop Gate the app's Twitch brand icon. Small centered icons retain the sidebar gradients. Subtle top-to-bottom background gradients share MoS Drop Gate state colors and borders: green running, red stopped, yellow attention and grey disconnected. Status tags such as �Stats running� and �Cycles stopped� are drawn below the icon in the same SVG. Native titles stay empty. Action/category menu icons have transparent backgrounds. The app shows one compact sample per plugin. Icon attribution is bundled in `licenses`.

From Marbles Stats, open **Stream Deck** and click **Install Marbles Stats plugin**. Windows opens the bundled `.streamDeckPlugin` file with Stream Deck. Confirm installation if asked. Expand **Marbles Stats Controls** in Stream Deck's actions list and drag each action to a key. Installation adds actions to the list; it does not overwrite an existing deck layout or choose key positions for the user.

Keep Marbles Stats open (minimized is fine). Each key displays the tracker�s actual state using its background, border and small status tag. Pressing the key requests the opposite enabled state and waits for confirmation. Failed commands turn yellow. Repeated presses are ignored while a request is pending. Disconnecting clears pending requests; reconnecting never replays an old command.

The page checks the current Windows user's Stream Deck plugin manifests under `%APPDATA%\Elgato\StreamDeck\Plugins`. Its existing buttons show **Install**, **Update** or **Reinstall**, with installed versions in their tooltips. Checks refresh every five seconds while the page is visible and when the app regains focus. Unreadable or malformed manifests remain unknown. This reports installation, independently of key placement or runtime connection.

## Local connection

The app binds a WebSocket listener to `127.0.0.1` on an OS-assigned port. A fresh Windows-generated 256-bit token and port are written to the current user's `%APPDATA%\com.marblesstats.app\streamdeck-connection.json` at startup. The plugin discovers and authenticates automatically, receives a small tracker-state packet and calls the app's existing tracker command. No parser, scoring or integration logic is duplicated. The connection rejects browser Origin headers, requires authentication before commands, bounds frame sizes, limits concurrent clients and serializes tracker operations with the app UI. No token is included in the plugin package or emitted to logs.

If the app closes or stops responding, keys switch to Disconnected. The plugin retries discovery automatically. An enabled tracker with a missing CSV shows a yellow background and a �no file� tag; pressing it stops the tracker. Start it again after resolving the missing-file problem. For command failures, consult Marbles Stats' Live Log.

## Development

Edit `com.marblesstats.controls.sdPlugin`, then run:

```sh
npm run streamdeck:check
npm run streamdeck:pack
```

The second command regenerates artwork from the sidebar renderer, bundles the JavaScript plugin for Node 20, then uses Elgato's official CLI to validate and package it into `public/streamdeck/com.marblesstats.controls.streamDeckPlugin`. Release executables embed that exact file and extract it to writable app data only when the user clicks Install. In development, Install reads the latest packaged file from the project so artwork/compatibility fixes do not reopen an older embedded installer. Normal frontend/release builds regenerate the package automatically. Increment the plugin manifest version when shipping plugin changes to existing users.

The focused checks use mock Stream Deck and app transports, including an isolated copy of the actual bundled plugin connected over real local WebSockets. They do not open either app or change live tracker state. Set STREAMDECK_TEST_NODE to an installed Stream Deck Node executable to check that runtime specifically. Rust bridge tests run with the backend suite on GitHub. The user confirmed that physical keys start and stop the trackers. The installed v1.0.5 bundle was verified against source and reloaded through Stream Deck. Final icon appearance and packaged-app restart/reconnect still require manual verification.

MoS Drop belongs to a separate product with its own bundled Windows installer, `public/streamdeck/com.mosdropgate.plugin.streamDeckPlugin` (v0.4.4). The **Install MoS Drop plugin** button selects that package through a dedicated native command. Both installers are embedded in release executables; debug builds read their current fixed project paths. Native installer changes require the normal Tauri backend reload. Drop Gate uses the same size sidebar Twitch SVG, state gradients and borders, plus a small live/offline/unknown status light. Connect Twitch in the key settings after installing.

Published bundle: the installer is the exact Windows x64 asset from [mosDropGate v0.4.4](https://github.com/smolpuff/mosDropGate/releases/tag/v0.4.4), including the custom-icon picker and per-key Live/Offline colors. SHA-256: `139f4ef564d76491a4282d8343c61edff94eb26f7e79eb82c9aea28a1ef30463`. The UI and installed-version comparison both identify this package as v0.4.4 (manifest version 0.4.4.0).

Drop Gate sources are maintained in the independent [mosDropGate repository](https://github.com/smolpuff/mosDropGate) (locally `../mosDropGate`). Publish its standalone release after source changes, verify the released Windows installer checksum, then replace the bundled Drop Gate package; `streamdeck:pack` regenerates only the Controls installer. The standalone Drop Gate Windows build and all 32 plugin tests passed on GitHub for Windows x64, macOS Apple Silicon and macOS Intel. Actual install, Twitch authorization and mobile-key appearance remain manual checks.

An offline Drop Gate press briefly overlays an X on that key for three seconds, then restores its normal channel-labelled artwork. Background status checks do not show this feedback.
